## How to install and play

1. Click the download link above. You get `Tales.Of.Vulcan.zip` (about 630 MB).
2. Right-click the zip and choose **Extract All**.
3. Open the extracted folder, then `Tales Of Vulkan` → `Windows`.
4. Double-click **`TalesofVulcan.exe`**.
5. If Windows SmartScreen warns you, click **More info**, then **Run anyway** (the game isn't code-signed).

Needs Windows 10/11 (64-bit) and a DirectX 12 graphics card. Every version is on the [Releases page](https://github.com/danyal-rashidi/tales-of-vulcan/releases).

## Controls

| Action | Key |
|---|---|
| Move / look | WASD / mouse |
| Jump | Space |
| Light attack (in the air: plunge attack) | Left click |
| Heavy attack | Right click |
| Dodge roll | Left Shift |
| Lock on | Middle mouse or Q |
