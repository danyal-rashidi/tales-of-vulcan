# Tales of Vulcan

A one-boss soulslike made for StormHacks: wake Vulcan, the Silver Tide, in a ruined Roman colosseum and take him down with a spear.

## ⬇️ [Download for Windows](https://github.com/danyal-rashidi/tales-of-vulcan/releases/latest/download/Tales.Of.Vulcan.zip)

Unzip it and run `Tales Of Vulkan\Windows\TalesofVulcan.exe` (Windows 10/11, 64-bit, DirectX 12 graphics card). If Windows SmartScreen warns you, click **More info** then **Run anyway**. All versions are on the [Releases page](https://github.com/danyal-rashidi/tales-of-vulcan/releases).

## Controls

| Action | Key |
|---|---|
| Move / look | WASD / mouse |
| Jump | Space |
| Light attack (in the air: plunge attack) | Left click |
| Heavy attack | Right click |
| Dodge roll | Left Shift |
| Lock on | Middle mouse or Q |
